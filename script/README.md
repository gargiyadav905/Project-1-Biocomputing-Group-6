# Project-1-Biocomputing-Group-6
The gene MT-ND1 was searched from NCBI ,Category-B.
Using API efetch, the required sequences and the accessions numbers were recorded.
To get the CDS-coordinates, GenBank record was fetched.
Then, the protein sequences were also fetched using the API.
The downloaded FASTA and GenBank is in the data/folder.
The Jupyter Notebook is stored in script/folder.
Then, the coding sequence was translated.
After that, the translated and the deposited amino acid sequences were compared for identity.
Then the translation was done using translate() function as well and both lengths were same.
